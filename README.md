# VLSI Task 2 - 4-Bit Ripple Carry Adder

## Objective

The objective of this task is to design and implement a **4-bit Ripple Carry Adder (RCA)** using Verilog HDL.

The design reuses the **1-bit Full Adder** module from Task 1 and connects four full adders together to perform 4-bit binary addition.

This task demonstrates hierarchical Verilog design, module instantiation, carry propagation, simulation, and waveform analysis.

## Tools Used

- Verilog HDL
- Icarus Verilog 13.0
- GTKWave 3.3.127
- MSYS2 UCRT64

## Project Description

A **4-bit Ripple Carry Adder** is constructed using four 1-bit full adders.

Each full adder adds one bit of `A` and `B`, along with the carry generated by the previous stage.

The carry propagates from the **Least Significant Bit (LSB)** to the **Most Significant Bit (MSB)**.

### Ripple Carry Adder Structure

```text
             carry[0]       carry[1]       carry[2]
                ↓              ↓              ↓
A[0], B[0] → FA0 → A[1], B[1] → FA1 → A[2], B[2] → FA2 → A[3], B[3] → FA3
                ↓              ↓              ↓              ↓
             Sum[0]         Sum[1]         Sum[2]         Sum[3]

Cin ─────→ FA0
FA3 ─────→ Cout
```

The design uses:

- `A[3:0]` — 4-bit input
- `B[3:0]` — 4-bit input
- `Cin` — input carry
- `Sum[3:0]` — 4-bit sum output
- `Cout` — output carry

## Ripple Carry Adder Verilog Code

```verilog
module rca_4bit(
    input  [3:0] A,
    input  [3:0] B,
    input        Cin,
    output [3:0] Sum,
    output       Cout
);

wire [3:0] carry;

full_adder fa0(
    .A(A[0]),
    .B(B[0]),
    .Cin(Cin),
    .Sum(Sum[0]),
    .Cout(carry[0])
);

full_adder fa1(
    .A(A[1]),
    .B(B[1]),
    .Cin(carry[0]),
    .Sum(Sum[1]),
    .Cout(carry[1])
);

full_adder fa2(
    .A(A[2]),
    .B(B[2]),
    .Cin(carry[1]),
    .Sum(Sum[2]),
    .Cout(carry[2])
);

full_adder fa3(
    .A(A[3]),
    .B(B[3]),
    .Cin(carry[2]),
    .Sum(Sum[3]),
    .Cout(Cout)
);

endmodule
```

## Testbench

The testbench applies different 4-bit input combinations to verify the operation of the Ripple Carry Adder.

```verilog
module tb_rca_4bit;

reg [3:0] A;
reg [3:0] B;
reg Cin;

wire [3:0] Sum;
wire Cout;

rca_4bit uut(
    .A(A),
    .B(B),
    .Cin(Cin),
    .Sum(Sum),
    .Cout(Cout)
);

initial begin
    $dumpfile("rca_4bit.vcd");
    $dumpvars(0, tb_rca_4bit);

    $display("A     B     Cin | Cout  Sum");
    $display("-----------------------------");

    A = 4'b0101; B = 4'b0011; Cin = 0;
    #10;
    $display("%b  %b   %b   |  %b    %b", A, B, Cin, Cout, Sum);

    A = 4'b1001; B = 4'b0110; Cin = 0;
    #10;
    $display("%b  %b   %b   |  %b    %b", A, B, Cin, Cout, Sum);

    A = 4'b1111; B = 4'b0001; Cin = 0;
    #10;
    $display("%b  %b   %b   |  %b    %b", A, B, Cin, Cout, Sum);

    A = 4'b1010; B = 4'b0101; Cin = 1;
    #10;
    $display("%b  %b   %b   |  %b    %b", A, B, Cin, Cout, Sum);

    $finish;
end

endmodule
```
